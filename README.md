# mwalterskirchen.dev

[![Deploy](https://github.com/mwalterskirchen/mwalterskirchen.dev/actions/workflows/deploy.yml/badge.svg)](https://github.com/mwalterskirchen/mwalterskirchen.dev/actions/workflows/deploy.yml)

My personal site, where I write about software engineering and list the talks I give.

[![mwalterskirchen.dev](https://mwalterskirchen.dev/og/site.png)](https://mwalterskirchen.dev)

## Highlights

- A pixel art theme with a parallax sky, a meadow footer and Lilly, a poodle you can play fetch with
- Open Graph cards generated for every post at build time
- Static pages served from Cloudflare Workers

Built with [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com) and [Takumi](https://takumi.kane.tw).

## Running locally

```bash
pnpm install
pnpm dev
```
